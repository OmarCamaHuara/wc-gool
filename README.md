# wc-gool

Repositório de **documentação** de uma plataforma de análise de mercados e rede social
para traders, inspirada no [TradingView](https://www.tradingview.com/).

- **Stack definida**: Java (backend) + React (frontend)
- **Este repo**: só documentação — regras de negócio, especificações e milestones em
  micro-tarefas executáveis por LLM. O código viverá em outro lugar.

📚 **Comece por aqui**: [`docs/README.md`](docs/README.md)

**Fase atual**: 0 — Descoberta e Alinhamento (dúvidas abertas em
[`docs/01-alinhamento/duvidas-e-decisoes.md`](docs/01-alinhamento/duvidas-e-decisoes.md)).
